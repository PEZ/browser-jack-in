# Impeccable Design Context

## Design Context

### Users
Developers, Clojure programmers, and power users who want to live-tamper with web pages through a REPL or auto-run userscripts. They work in tight feedback loops: evaluate code, see DOM change, iterate. Many use AI-assisted workflows where an agent drives the REPL. The popup UI is phone-sized (browser extension constraint), so mobile-density layout techniques apply - minus touch targets.

### Brand Personality
**Curious, powerpacked, helpful.**

The extension should feel like a capable companion that makes you more powerful, not a control panel you have to wrestle. It packs real capability into small surfaces without feeling cramped. It is genuinely helpful - guiding without patronizing, dense without overwhelming.

### Emotional Goals (priority order)
1. **Empowered** - "I can do anything to this page"
2. **In control** - everything is clear and predictable
3. **Delighted** - small moments of joy and craft
4. **Focused** - the tool stays out of the way
5. **Wizard-like** - powerful and a bit magical

### Aesthetic Direction
Push the current "friendly technical" tone toward **premium/crafted**. The foundation is solid - warm Clojure brand colors (blue, green, gold), practical layouts, clear status communication. The goal is to elevate every surface so it feels intentionally designed, not just functional.

### References
- **NAIS (nais.kystverket.no)** - Packs and surfaces dense maritime information without feeling cramped or overcrowded. Slick, consistent, deeply intuitive UX. The benchmark for "someone who cares deeply about usability."

### Anti-references
- **Desktop Gmail** - The opposite of what Epupp should feel like. Cluttered, inconsistent, feels like nobody cared about the details.

### Design Principles
1. **Density with breathing room** - Pack capability into small surfaces, but give every element enough space to be immediately readable. NAIS-level information density.
2. **Premium in the details** - Elevation comes from refined spacing, thoughtful transitions, and consistent visual language - not from decoration or complexity.
3. **Brand-coherent warmth** - The Clojure blue/green/gold palette is identity, not decoration. Use it with intention and restraint so the brand reads as crafted, not painted on.
4. **Phone-sized discipline** - The popup lives in browser-extension dimensions. Every pixel decision should be tested against that constraint. Techniques from mobile UI design apply.
5. **Status at a glance** - Connection state, script matches, errors, and REPL status must be instantly scannable. The user should never have to search for "what's happening right now."

### Existing Design Foundation
- **Palette**: Clojure blue (#5881d8), green (#91dc47), gold (#FFDC73) on warm neutrals (#fcfbf9 / #1c2028 dark)
- **Typography**: Avenir Next / system sans + monospace for code, 11-15px scale
- **Spacing**: 4pt token scale (4, 8, 12, 16, 20px)
- **Theme**: Light default, dark via prefers-color-scheme
- **Components**: Action buttons, collapsible sections, script cards, status banners, result stream, branded header gradient
- **Accessibility**: WCAG AA, reduced-motion support, standard best practices
